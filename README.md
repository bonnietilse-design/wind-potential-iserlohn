# wind-potential-iserlohn
ArcPy-Workflow zur Ermittlung von Windpark-Potenzialflächen in Iserlohn (Märkischer Kreis, NRW). Projiziert, filtert und importiert Geodaten, wendet 54 harte und weiche Kriterien aus einer CSV-Kriterientabelle per Puffer- und Union-Analyse an, bewertet die Potenzialflächen und entfernt zu kleine oder zu schmale Flächen.
